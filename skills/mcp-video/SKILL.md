# mcp-video compatibility

The project is now Kinocut. Follow [`../kinocut/SKILL.md`](../kinocut/SKILL.md) and use
`$kinocut` for new work. Existing `mcp-video` commands and `mcp_video` imports remain
supported through at least Kinocut 1.8.x.
